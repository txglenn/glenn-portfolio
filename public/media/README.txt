MEDIA FOLDER — DROP FILES HERE
══════════════════════════════

headshots/
  → headshot.jpg   — Your profile photo. Drop it here and the About section
                     picks it up automatically. No code changes needed.
                     Recommended: square crop, minimum 400×400px.

portfolio/
  → Screenshots or mockup images for portfolio project cards.
     Name them descriptively, e.g. spring-fed-surf.jpg, hvac-client.jpg.
     Recommended: 1200×800px, .jpg or .webp.

hero/
  → Background images or video for the hero section if you ever want
     to swap the current gradient/dot-grid for a real photo or video.
     Images: recommend 1920×1080px minimum.
     Videos: .mp4 (H.264), keep under 8MB for fast load.
     Unused until you wire them into Hero.tsx.

All files in /public/ are served at the root URL, so:
  public/media/headshots/headshot.jpg  →  /media/headshots/headshot.jpg
